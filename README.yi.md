## פֿעיִקייטן

- טעקע־פּאַטן אינעם טערמינאַל זענען לינקען. ווען אַן אַגענט שרײַבט `⎿ M src/app.ts` אָדער `src/app.ts:42:7`, ווערט דער פּאַט בלוי; אַ קליק עפֿנט די טעקע בײַ יענער שורה.
- פּראָיעקט־בוים לינקס, רעדאַקטאָר אין מיטן, טערמינאַל אונטן.
- טוישט די ערטער פֿונעם טערמינאַל און פּראָיעקט־בוים (⌃⌘T), כּדי דער טערמינאַל זאָל זײַן לינקס מיט דער גאַנצער הייך. פֿאַרגרעסערט אים מיט ⇧⌘↩.
- טעקעס ווערן אויטאָמאַטיש אָפּגעהיט נאָך אַ שרײַבפּויזע פֿון 500 ms און פֿאַרן פֿאַרמאַכן. בײַ דרויסנדיקע ענדערונגען אָדער דורכגעפֿאַלענעם אָפּהיטן בלײַבן אײַערע ענדערונגען אינעם קוויטל, מיט דער מעגלעכקייט אָפּצוהיטן אַ קאָפּיע.
- פֿאַרמאַכן אַ טערמינאַל מיט לויפֿנדיקע באַפֿעלן פֿאָדערט באַשטעטיקונג, אויך פֿאַר הינטערגרונט־אַרבעט און בײַם אַרויסגיין פֿון דער אַפּליקאַציע. באַהאַלטן דעם פּאַנעל לאָזט סעסיעס ווײַטער לויפֿן.
- טערמינאַלן ניצן Metal לויטן פֿעליקייט; דער GPU־צייכענונג־בײַטל איז אין זען. זוכט אינעם רעזולטאַט מיט ⌘F; נײַע קוויטלעך ירשענען דעם איצטיקן אַרבעטס־קאַטאַלאָג.
- Shift+Enter האַלט אויף דאָס אַרײַנגעבן פֿון פֿראַגעס מיט עטלעכע שורות. מען קען אַרײַנקלעבן פֿילשורותדיקן טעקסט, טעקעס און בילדער; בילדער בלײַבן ווי צײַטווײַליקע PNG, און זייערע פּאַטן ווערן אַרײַנגעלייגט אין גענדזן־פֿיסלעך.
- דער פֿאָרויסווײַז פֿון Markdown און HTML לעבן דעם טעקסט באַנײַט זיך בשעתן שרײַבן (⇧⌘V אָדער די קנעפּלעך אויבן רעכטס אינעם קוויטל). Markdown ווערט געוויזן מיט cmark-gfm, וואָס GitHub ניצט: טאַבעלעס, אויפֿגאַבע־רשימות, דורכגעשטראָכענער טעקסט און אויטאָמאַטישע לינקען.
- זוכן אומעטום: דריקט Shift צוויי מאָל צו געפֿינען יעדע טעקע אינעם פּראָיעקט לויט אַן אומגעפֿער צופּאַסנדיקן נאָמען.
- דערקענט מקור־טעקעס מיט אַ קאַטאַלאָג פֿון 915 שפּראַך־ און פֿאָרמאַט־נעמען, אַרײַנגערעכנט טעקע־נעמען, צונויפֿגעזעצטע פֿאַרלענגערונגען און סקריפּט־אינטערפּרעטערס. אַלע 297 Prism־טיילן (291 זעלבשטענדיקע גראַמאַטיקן און 6 העלפֿער) זענען אַרײַנגענומען און ווערן געלאָדן לויטן דאַרף. פֿאָרמאַטן אָן גראַמאַטיק ניצן פּשוטע טעקסט־הויכפּונקטירונג.
- דער צובינד האָט 108 שפּראַך־ברירות. בײַט מיד אין שפּראַך־מעניו אָדער גייט לויט דער סיסטעם־שפּראַך. די ברירה ווערט געדענקט; אָפֿענע טעקעס, נישט אָפּגעהיטע ענדערונגען און טערמינאַל־סעסיעס בלײַבן אָפֿן. אין אַראַבישע, העברעיִשע און אַנדערע רעכטס־צו־לינקס צובינדן בלײַבן קאָד, פֿאָרויסווײַז און טערמינאַל־רעזולטאַטן לינקס־צו־רעכטס. די איבערזעצונגען ווערן געשריבן גלײַך פֿון ענגלישע טעקסטן לויטן קאָנטעקסט פֿונעם רעדאַקטאָר און טערמינאַל. סיסטעם־פּאַנעלן גייען לויט די macOS שפּראַך־אײַנשטעלונגען. דער קאַטאַלאָג נעמט נישט אַרײַן יעדע נאַטירלעכע אָדער פּראָגראַמיר־שפּראַך. זעט [איבערזעצן Sumi](CONTRIBUTING.md#translating-sumi).
- דער ליכטיקער און טונקעלער אויסזען גייען לויטן סיסטעם.

## אַראָפּלאָדן

- [נײַסטע אויסגאַבע](../../releases/latest)
- [נאַכט־ווערסיע](../../releases/tag/nightly): ווערט נײַ געבויט בײַ יעדער ענדערונג אין `main`.

לאָדט אַראָפּ `Sumi.zip`, פּאַקט אויס און פֿירט Sumi אַריבער אין Applications. איין ווערסיע אַרבעט אויף Apple silicon און Intel Mac־מאַשינען.

Sumi איז נישט אונטערגעשריבן מיט אַן Apple Developer ID, דערפֿאַר בלאָקירט macOS דאָס ערשטע עפֿענען. עפֿנט סיסטעם־אײַנשטעלונגען › פּריוואַטקייט און זיכערהייט און קליקט סײַ ווי עפֿענען, אָדער לאָזט לויפֿן:

```sh
xattr -dr com.apple.quarantine /Applications/Sumi.app
```

## פֿאָדערונגען

macOS 14 אָדער נײַער. צום בויען דאַרף מען Xcode 26 אָדער נײַער (Swift 6.2).

## בויען פֿונעם מקור

```sh
make app       # build/Sumi.app (universal: Apple silicon and Intel)
make run       # debug build, then open it
make install   # copy to /Applications
```

עפֿנט אַ טעקע־זאַמלונג ווי אַ פּראָיעקט דורך טעקע › עפֿענען… (⌘O), אָדער פֿון דער באַפֿעל־שורה:

```sh
open -a Sumi path/to/project
```
