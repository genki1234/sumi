# Sumi

macOS ਲਈ ਇੱਕ ਹਲਕਾ ਟੈਕਸਟ ਸੰਪਾਦਕ, ਜੋ AI ਕੋਡਿੰਗ ਏਜੰਟਾਂ ਨਾਲ ਕੰਮ ਕਰਨ ਲਈ ਬਣਾਇਆ ਗਿਆ ਹੈ। ਖੁੱਲ੍ਹਾ ਸਰੋਤ (MIT)।

ਆਪਣੇ ਏਜੰਟ ਨੂੰ ਅੰਦਰਲੇ ਟਰਮੀਨਲ ਵਿੱਚ ਚਲਾਓ, ਉਸ ਵੱਲੋਂ ਬਦਲੀਆਂ ਫ਼ਾਈਲਾਂ ਨੂੰ ਕਲਿੱਕ ਕਰਕੇ ਖੋਲ੍ਹੋ ਅਤੇ ਉਸ ਦੇ ਲਿਖੇ Markdown ਨੂੰ ਸਜਾਏ ਹੋਏ ਸਫ਼ਿਆਂ ਵਾਂਗ ਪੜ੍ਹੋ।

## ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ

- ਟਰਮੀਨਲ ਵਿੱਚ ਫ਼ਾਈਲਾਂ ਦੇ ਪਾਥ ਲਿੰਕ ਹੁੰਦੇ ਹਨ। ਜਦੋਂ ਕੋਡਿੰਗ ਏਜੰਟ `⎿ M src/app.ts` ਜਾਂ `src/app.ts:42:7` ਦਿਖਾਉਂਦਾ ਹੈ, ਤਾਂ ਪਾਥ ਨੀਲਾ ਹੋ ਜਾਂਦਾ ਹੈ ਅਤੇ ਕਲਿੱਕ ਕਰਨ ਨਾਲ ਫ਼ਾਈਲ ਉਸ ਲਾਈਨ ਉੱਤੇ ਖੁੱਲ੍ਹਦੀ ਹੈ।
- ਖੱਬੇ ਪਾਸੇ ਪ੍ਰੋਜੈਕਟ ਟ੍ਰੀ, ਵਿਚਕਾਰ ਸੰਪਾਦਕ ਅਤੇ ਹੇਠਾਂ ਟਰਮੀਨਲ ਹੈ।
- ਟਰਮੀਨਲ ਅਤੇ ਪ੍ਰੋਜੈਕਟ ਦੀ ਥਾਂ ਬਦਲੋ (⌃⌘T) ਤਾਂ ਜੋ ਖੱਬੇ ਪਾਸੇ ਪੂਰੀ ਉਚਾਈ ਵਾਲਾ ਟਰਮੀਨਲ ਮਿਲੇ। ⇧⌘↩ ਨਾਲ ਟਰਮੀਨਲ ਪੂਰਾ ਵੱਡਾ ਕਰੋ।
- ਟਾਈਪ ਕਰਨ ਵਿੱਚ 500 ms ਦਾ ਵਿਰਾਮ ਆਉਣ ਉੱਤੇ ਅਤੇ ਬੰਦ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਫ਼ਾਈਲਾਂ ਆਪਣੇ ਆਪ ਸੰਭਾਲੀਆਂ ਜਾਂਦੀਆਂ ਹਨ। ਬਾਹਰੀ ਬਦਲਾਅ ਜਾਂ ਸੰਭਾਲਣ ਵਿੱਚ ਅਸਫਲਤਾ ਹੋਣ ਉੱਤੇ ਤੁਹਾਡੀਆਂ ਸੋਧਾਂ ਟੈਬ ਵਿੱਚ ਰਹਿੰਦੀਆਂ ਹਨ ਅਤੇ ਤੁਸੀਂ ਇੱਕ ਕਾਪੀ ਸੰਭਾਲ ਸਕਦੇ ਹੋ।
- ਚੱਲਦੀਆਂ ਕਮਾਂਡਾਂ ਵਾਲਾ ਟਰਮੀਨਲ ਬੰਦ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਪੁਸ਼ਟੀ ਮੰਗੀ ਜਾਂਦੀ ਹੈ। ਇਸ ਵਿੱਚ ਪਿੱਛੇ ਚੱਲਦੇ ਕੰਮ ਅਤੇ ਐਪ ਬੰਦ ਕਰਨਾ ਵੀ ਸ਼ਾਮਲ ਹਨ। ਪੈਨਲ ਲੁਕਾਉਣ ਨਾਲ ਸੈਸ਼ਨ ਚੱਲਦੇ ਰਹਿੰਦੇ ਹਨ।
- ਟਰਮੀਨਲ ਮੂਲ ਰੂਪ ਵਿੱਚ Metal ਵਰਤਦੇ ਹਨ। ਦਿੱਖ ਮੀਨੂ ਵਿੱਚ GPU ਰੈਂਡਰਿੰਗ ਦਾ ਵਿਕਲਪ ਹੈ। ⌘F ਨਾਲ ਆਉਟਪੁੱਟ ਵਿੱਚ ਲੱਭੋ; ਨਵੀਆਂ ਟੈਬਾਂ ਮੌਜੂਦਾ ਕੰਮ ਵਾਲੀ ਡਾਇਰੈਕਟਰੀ ਲੈਂਦੀਆਂ ਹਨ।
- Shift+Enter ਨਾਲ ਪ੍ਰੌਮਪਟ ਵਿੱਚ ਕਈ ਲਾਈਨਾਂ ਲਿਖੀਆਂ ਜਾ ਸਕਦੀਆਂ ਹਨ। ਕਈ ਲਾਈਨਾਂ ਵਾਲਾ ਟੈਕਸਟ, ਫ਼ਾਈਲਾਂ ਅਤੇ ਤਸਵੀਰਾਂ ਪੇਸਟ ਕੀਤੀਆਂ ਜਾ ਸਕਦੀਆਂ ਹਨ; ਤਸਵੀਰਾਂ ਅਸਥਾਈ PNG ਫ਼ਾਈਲਾਂ ਵਜੋਂ ਰੱਖੀਆਂ ਜਾਂਦੀਆਂ ਹਨ ਅਤੇ ਉਨ੍ਹਾਂ ਦੇ ਪਾਥ ਹਵਾਲਾ ਚਿੰਨ੍ਹਾਂ ਵਿੱਚ ਪਾਏ ਜਾਂਦੇ ਹਨ।
- Markdown ਅਤੇ HTML ਦੀ ਝਲਕ ਟੈਕਸਟ ਦੇ ਨਾਲ ਦਿਖਦੀ ਹੈ ਅਤੇ ਟਾਈਪ ਕਰਦਿਆਂ ਅੱਪਡੇਟ ਹੁੰਦੀ ਹੈ (⇧⌘V ਜਾਂ ਟੈਬ ਦੇ ਉੱਪਰ ਸੱਜੇ ਪਾਸੇ ਦੇ ਬਟਨ)।
  Markdown ਨੂੰ cmark-gfm ਨਾਲ ਦਿਖਾਇਆ ਜਾਂਦਾ ਹੈ, ਜੋ GitHub ਵੀ ਵਰਤਦਾ ਹੈ: ਟੇਬਲਾਂ, ਕੰਮਾਂ ਦੀਆਂ ਸੂਚੀਆਂ, ਕੱਟਿਆ ਹੋਇਆ ਟੈਕਸਟ ਅਤੇ ਆਪਣੇ ਆਪ ਬਣਦੇ ਲਿੰਕ ਸਮਰਥਿਤ ਹਨ।
- ਹਰ ਥਾਂ ਲੱਭੋ: ਪ੍ਰੋਜੈਕਟ ਦੀ ਕੋਈ ਵੀ ਫ਼ਾਈਲ ਨਾਂ ਦੇ ਅੰਦਾਜ਼ਨ ਮਿਲਾਣ ਨਾਲ ਲੱਭਣ ਲਈ Shift ਦੋ ਵਾਰ ਦਬਾਓ।
- 915 ਭਾਸ਼ਾਵਾਂ ਅਤੇ ਫ਼ਾਈਲ ਫਾਰਮੈਟਾਂ ਦੇ ਨਾਂ ਵਾਲੀ ਸੂਚੀ ਨਾਲ ਫ਼ਾਈਲ ਦੇ ਨਾਂ, ਮਿਲੇ-ਜੁਲੇ ਐਕਸਟੈਂਸ਼ਨਾਂ ਅਤੇ ਸਕ੍ਰਿਪਟ ਇੰਟਰਪ੍ਰੀਟਰਾਂ ਤੋਂ ਸਰੋਤ ਫ਼ਾਈਲਾਂ ਪਛਾਣੀਆਂ ਜਾਂਦੀਆਂ ਹਨ। Prism ਦੇ ਸਾਰੇ 297 ਹਿੱਸੇ (291 ਸੁਤੰਤਰ ਵਿਆਕਰਨ ਅਤੇ ਛੇ ਸਹਾਇਕ ਹਿੱਸੇ) ਨਾਲ ਦਿੱਤੇ ਗਏ ਹਨ ਅਤੇ ਲੋੜ ਪੈਣ ਉੱਤੇ ਲੋਡ ਹੁੰਦੇ ਹਨ। ਵਿਆਕਰਨ ਤੋਂ ਬਿਨਾਂ ਵਾਲੇ ਫਾਰਮੈਟਾਂ ਲਈ ਟੈਕਸਟ ਦੀ ਮੁੱਢਲੀ ਰੰਗਾਈ ਹੁੰਦੀ ਹੈ।
- ਇੰਟਰਫੇਸ ਵਿੱਚ ਭਾਸ਼ਾ ਦੇ 108 ਵਿਕਲਪ ਹਨ। ਭਾਸ਼ਾ ਮੀਨੂ ਤੋਂ ਤੁਰੰਤ ਬਦਲੋ ਜਾਂ ਸਿਸਟਮ ਦੀ ਭਾਸ਼ਾ ਵਰਤੋ। ਚੋਣ ਯਾਦ ਰੱਖੀ ਜਾਂਦੀ ਹੈ; ਖੁੱਲ੍ਹੀਆਂ ਫ਼ਾਈਲਾਂ, ਨਾ ਸੰਭਾਲੀਆਂ ਸੋਧਾਂ ਅਤੇ ਟਰਮੀਨਲ ਸੈਸ਼ਨ ਜਾਰੀ ਰਹਿੰਦੇ ਹਨ। ਅਰਬੀ, ਹਿਬਰੂ ਅਤੇ ਸੱਜੇ ਤੋਂ ਖੱਬੇ ਲਿਖੀਆਂ ਜਾਣ ਵਾਲੀਆਂ ਹੋਰ ਭਾਸ਼ਾਵਾਂ ਦੇ ਇੰਟਰਫੇਸ ਵਿੱਚ ਵੀ ਕੋਡ, ਝਲਕਾਂ ਅਤੇ ਟਰਮੀਨਲ ਆਉਟਪੁੱਟ ਖੱਬੇ ਤੋਂ ਸੱਜੇ ਰਹਿੰਦੇ ਹਨ।
  ਅਨੁਵਾਦ ਅੰਗਰੇਜ਼ੀ ਮੂਲ ਲਿਖਤ ਅਤੇ ਸੰਪਾਦਕ ਤੇ ਟਰਮੀਨਲ ਵਿੱਚ ਉਸ ਦੀ ਵਰਤੋਂ ਦੇ ਸੰਦਰਭ ਤੋਂ ਸਿੱਧੇ ਲਿਖੇ ਜਾਂਦੇ ਹਨ। ਸਿਸਟਮ ਦੇ ਦਿੱਤੇ ਪੈਨਲ macOS ਦੀਆਂ ਭਾਸ਼ਾ ਸੈਟਿੰਗਾਂ ਮੰਨਦੇ ਹਨ। ਇਹ ਸੂਚੀ ਦੁਨੀਆ ਦੀਆਂ ਸਾਰੀਆਂ ਕੁਦਰਤੀ ਜਾਂ ਪ੍ਰੋਗਰਾਮਿੰਗ ਭਾਸ਼ਾਵਾਂ ਨੂੰ ਸ਼ਾਮਲ ਨਹੀਂ ਕਰਦੀ। [Sumi ਦਾ ਅਨੁਵਾਦ](CONTRIBUTING.md#translating-sumi) ਵੇਖੋ।
- ਹਲਕੀ ਅਤੇ ਗੂੜ੍ਹੀ ਦਿੱਖ ਸਿਸਟਮ ਦੇ ਅਨੁਸਾਰ ਬਦਲਦੀ ਹੈ।

## ਡਾਊਨਲੋਡ

- [ਸਭ ਤੋਂ ਨਵਾਂ ਰਿਲੀਜ਼](../../releases/latest)
- [Nightly ਬਿਲਡ](../../releases/tag/nightly): `main` ਵਿੱਚ ਹਰ ਬਦਲਾਅ ਉੱਤੇ ਮੁੜ ਬਣਦਾ ਹੈ।

`Sumi.zip` ਡਾਊਨਲੋਡ ਕਰੋ, ਖੋਲ੍ਹ ਕੇ ਉਸ ਵਿੱਚੋਂ Sumi ਨੂੰ Applications ਵਿੱਚ ਰੱਖੋ। ਇੱਕੋ ਬਿਲਡ Apple silicon ਅਤੇ Intel ਦੋਹਾਂ ਕਿਸਮਾਂ ਦੇ Mac ਉੱਤੇ ਚੱਲਦਾ ਹੈ।

Sumi ਉੱਤੇ Apple Developer ID ਨਾਲ ਦਸਤਖ਼ਤ ਨਹੀਂ ਕੀਤੇ ਗਏ, ਇਸ ਲਈ macOS ਪਹਿਲੀ ਵਾਰ ਖੋਲ੍ਹਣ ਤੋਂ ਰੋਕਦਾ ਹੈ। System Settings › Privacy & Security ਖੋਲ੍ਹ ਕੇ Open Anyway ਦਬਾਓ ਜਾਂ ਇਹ ਕਮਾਂਡ ਚਲਾਓ:

```sh
xattr -dr com.apple.quarantine /Applications/Sumi.app
```

## ਲੋੜਾਂ

macOS 14 ਜਾਂ ਇਸ ਤੋਂ ਨਵਾਂ। ਬਿਲਡ ਲਈ Xcode 26 ਜਾਂ ਇਸ ਤੋਂ ਨਵਾਂ (Swift 6.2) ਚਾਹੀਦਾ ਹੈ।

## ਸਰੋਤ ਤੋਂ ਬਿਲਡ

```sh
make app       # build/Sumi.app (universal: Apple silicon and Intel)
make run       # debug build, then open it
make install   # copy to /Applications
```

ਫ਼ਾਈਲ › ਖੋਲ੍ਹੋ… (⌘O) ਨਾਲ ਜਾਂ ਕਮਾਂਡ ਲਾਈਨ ਤੋਂ ਕਿਸੇ ਫੋਲਡਰ ਨੂੰ ਪ੍ਰੋਜੈਕਟ ਵਜੋਂ ਖੋਲ੍ਹੋ:

```sh
open -a Sumi path/to/project
```
