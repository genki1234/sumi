## មុខងារ

- ផ្លូវឯកសារក្នុងស្ថានីយជាតំណ។ ពេលភ្នាក់ងារសរសេរកូដបញ្ចេញ `⎿ M src/app.ts` ឬ `src/app.ts:42:7` ផ្លូវនឹងប្រែជាពណ៌ខៀវ ហើយការចុចនឹងបើកឯកសារនៅជួរនោះ។
- មែកធាងគម្រោងនៅឆ្វេង កម្មវិធីកែសម្រួលនៅកណ្ដាល និងស្ថានីយនៅខាងក្រោម។
- ប្ដូរទីតាំងស្ថានីយនិងមែកធាងគម្រោង (⌃⌘T) ដើម្បីដាក់ស្ថានីយកម្ពស់ពេញនៅឆ្វេង។ ពង្រីកស្ថានីយអតិបរមាដោយ ⇧⌘↩។
- ឯកសាររក្សាទុកដោយស្វ័យប្រវត្តិបន្ទាប់ពីឈប់វាយ 500 ms និងមុនពេលបិទ។ ការផ្លាស់ប្ដូរពីខាងក្រៅនិងការរក្សាទុកបរាជ័យទុកការកែសម្រួលរបស់អ្នកក្នុងផ្ទាំង ដោយមានជម្រើសរក្សាទុកច្បាប់ចម្លង។
- ការបិទស្ថានីយដែលមានពាក្យបញ្ជាកំពុងដំណើរការត្រូវការការបញ្ជាក់ រួមទាំងការងារផ្ទៃខាងក្រោយនិងការចាកចេញពីកម្មវិធី។ ការលាក់ផ្ទាំងមិនបញ្ឈប់សម័យការងារទេ។
- ស្ថានីយប្រើ Metal តាមលំនាំដើម ហើយមានប៊ូតុងប្ដូរ បង្ហាញដោយ GPU ក្នុង ទិដ្ឋភាព។ ស្វែងរកលទ្ធផលដោយ ⌘F; ផ្ទាំងថ្មីទទួលយកថតធ្វើការបច្ចុប្បន្ន។
- Shift+Enter រក្សាការបញ្ចូលសំណើច្រើនជួរ។ ការបិទភ្ជាប់គាំទ្រអត្ថបទច្រើនជួរ ឯកសារ និងរូបភាព; រូបភាពត្រូវរក្សាជា PNG បណ្ដោះអាសន្ន ហើយបញ្ចូលជាផ្លូវនៅក្នុងសញ្ញាសម្រង់។
- ទិដ្ឋភាពជាមុន Markdown និង HTML នៅជាប់អត្ថបទធ្វើបច្ចុប្បន្នភាពពេលវាយ (⇧⌘V ឬប៊ូតុងខាងលើស្ដាំនៃផ្ទាំង)។ Markdown បង្ហាញដោយ cmark-gfm ដែល GitHub ប្រើ៖ តារាង បញ្ជីកិច្ចការ អត្ថបទឆូត និងតំណស្វ័យប្រវត្តិ។
- ស្វែងរកគ្រប់ទីកន្លែង៖ ចុច Shift ពីរដង ដើម្បីរកឯកសារណាមួយក្នុងគម្រោងតាមការផ្គូផ្គងឈ្មោះប្រហាក់ប្រហែល។
- ស្គាល់ឯកសារកូដប្រភពតាមកាតាឡុកឈ្មោះភាសានិងទម្រង់ឯកសារ 915 រួមទាំងឈ្មោះឯកសារ កន្ទុយឯកសារផ្សំ និងកម្មវិធីបកស្រាយស្គ្រីប។ សមាសភាគ Prism ទាំង 297 (វេយ្យាករណ៍ឯករាជ្យ 291 និងជំនួយការ 6) មានភ្ជាប់មកស្រាប់ ហើយផ្ទុកនៅពេលត្រូវការ។ ទម្រង់គ្មានវេយ្យាករណ៍ប្រើការរំលេចអត្ថបទមូលដ្ឋាន។

## ទាញយក

- [កំណែដែលបានចេញផ្សាយ](../../releases)
- [កំណែពេលយប់](../../releases/tag/nightly): បង្កើតឡើងវិញរាល់ការផ្លាស់ប្ដូរនៅ `main`។

ទាញយក `Sumi.zip` ពន្លាឯកសារ ហើយផ្លាស់ទី Sumi ទៅ Applications។ កំណែតែមួយដំណើរការលើ Mac Apple silicon និង Intel។

Sumi មិនបានចុះហត្ថលេខាដោយ Apple Developer ID ដូច្នេះ macOS រារាំងការបើកដំបូង។ បើកការកំណត់ប្រព័ន្ធ › ឯកជនភាពនិងសុវត្ថិភាព រួចចុចបើកទោះយ៉ាងណា ឬដំណើរការ៖

```sh
xattr -dr com.apple.quarantine /Applications/Sumi.app
```

## តម្រូវការ

macOS 14 ឬថ្មីជាង។ ការបង្កើតត្រូវការ Xcode 26 ឬថ្មីជាង (Swift 6.2)។

## បង្កើតពីកូដប្រភព

```sh
make app       # build/Sumi.app (universal: Apple silicon and Intel)
make run       # debug build, then open it
make install   # copy to /Applications
```

បើកថតជាគម្រោងពី ឯកសារ › បើក… (⌘O) ឬពីបន្ទាត់ពាក្យបញ្ជា៖

```sh
open -a Sumi path/to/project
```
