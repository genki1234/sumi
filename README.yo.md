# Sumi

Olóòtú ọ̀rọ̀ macOS tí kò wuwo, tí a dá láti ṣiṣẹ́ pọ̀ pẹ̀lú àwọn aṣojú AI tó ń kọ kóòdù. Orísun rẹ ṣí sí gbogbo ènìyàn (MIT).

Ṣiṣẹ́ aṣojú rẹ nínú terminal tí ó wà nínú rẹ, tẹ àwọn fáìlì tí ó yí padà láti ṣí wọn, kí o sì ka Markdown tí ó kọ gẹ́gẹ́ bí ojú ìwé tí a ti ṣètò.

## Àwọn ohun tí ó lè ṣe

- Ọ̀nà fáìlì nínú terminal jẹ́ ìjápọ̀. Bí aṣojú bá fi `⎿ M src/app.ts` tàbí `src/app.ts:42:7` hàn, ọ̀nà náà yóò di búlúù; tẹ̀ ẹ́ láti ṣí fáìlì ní ìlà náà.
- Ìwò iṣẹ́ àkànṣe ní òsì, olóòtú ní àárín, terminal ní ìsàlẹ̀.
- Pààrọ̀ ipò terminal àti ìwò iṣẹ́ àkànṣe (⌃⌘T) láti fi terminal tó gba gbogbo gíga sí òsì. Mú terminal tóbi pẹ̀lú ⇧⌘↩.
- Fáìlì máa ń fi ara rẹ̀ pamọ́ lẹ́yìn ìsinmi títẹ̀ fún 500 ms àti kí a tó tì í. Tí ìyípadà láti òde tàbí ìkùnà fífipamọ́ bá ṣẹlẹ̀, àtúnṣe rẹ á wà nínú táàbù, ó sì ṣeé fi ẹ̀dà kan pamọ́.
- Títí terminal tí àṣẹ ṣì ń ṣiṣẹ́ nínú rẹ ń béèrè ìmúdájú, pẹ̀lú iṣẹ́ abẹ́lẹ̀ àti jíjáde kúrò nínú ohun èlò. Fífi pánẹ́ẹ̀lì pamọ́ kò dá àwọn àkókò iṣẹ́ dúró.
- Terminal ń lo Metal ní àiyipada; bọ́tìnì yíya àwòrán pẹ̀lú GPU wà nínú Ìwò. Wá nínú èsì pẹ̀lú ⌘F; táàbù tuntun gba fódà iṣẹ́ tó ń lò lọ́wọ́.
- Shift+Enter pa ìbéèrè olópọ̀ ìlà mọ́. A lè lẹ ọ̀rọ̀ olópọ̀ ìlà, fáìlì àti àwòrán mọ́; àwòrán wà gẹ́gẹ́ bí PNG fún ìgbà díẹ̀, a sì fi ọ̀nà wọn sínú àmì àyọlò.
- Àwòtẹ́lẹ̀ Markdown àti HTML wà lẹ́gbẹ̀ẹ́ ọ̀rọ̀, ó sì ń yí padà bí o ṣe ń tẹ̀ (⇧⌘V tàbí bọ́tìnì ní òkè ọ̀tún táàbù). Markdown ń lo cmark-gfm tí GitHub ń lò: tábìlì, àtòjọ iṣẹ́, ọ̀rọ̀ tí a la ìlà lé àti ìjápọ̀ aládàáṣiṣẹ́.
- Wá níbi gbogbo: tẹ Shift lẹ́ẹ̀mejì láti rí fáìlì èyíkéyìí nínú iṣẹ́ àkànṣe nípa orúkọ tó fẹ́rẹ̀ẹ́ bá mu.
- Ó mọ fáìlì orísun nípa àkójọ orúkọ èdè àti ọ̀nà fáìlì 915, pẹ̀lú orúkọ fáìlì, àfikún fáìlì alápọ̀ àti atúmọ̀ ìlànà script. Gbogbo ẹ̀yà Prism 297 (291 gírámà olómìnira àti 6 olùrànlọ́wọ́) wà nínú rẹ, a sì ń gbé wọn wọlé nígbà tí a nílò wọn. Ọ̀nà fáìlì tí kò ní gírámà ń lo fífi àwọ̀ ọ̀rọ̀ ìpìlẹ̀ hàn.
- Ìrísí ìṣàkóso ní àṣàyàn èdè 108. Lo àkójọ Èdè láti yí padà lẹ́sẹ̀kẹsẹ̀ tàbí tẹ̀lé èdè ẹ̀rọ. Ó rántí àṣàyàn; fáìlì tí ó ṣí, àtúnṣe tí a kò tíì fi pamọ́ àti àkókò terminal ṣì ṣí. Nínú èdè Lárúbáwá, Hébérù àti ìrísí ọ̀tún-sí-òsì mìíràn, kóòdù, àwòtẹ́lẹ̀ àti èsì terminal ṣì jẹ́ òsì-sí-ọ̀tún. A kọ ìtumọ̀ tààrà láti ọ̀rọ̀ Gẹ̀ẹ́sì, ní ìbámu pẹ̀lú olóòtú àti terminal. Pánẹ́ẹ̀lì ẹ̀rọ tẹ̀lé ètò èdè macOS. Àkójọ náà kò gba gbogbo èdè àdánidá tàbí èdè ìkọ̀wé ètò. Wo [Títúmọ̀ Sumi](CONTRIBUTING.md#translating-sumi).
- Ìrísí ìmọ́lẹ̀ àti òkùnkùn tẹ̀lé ẹ̀rọ.

## Gba sílẹ̀

- [Ẹ̀yà tuntun jù](../../releases/latest)
- [Ẹ̀yà òru](../../releases/tag/nightly): a tún ń kọ́ ọ ní gbogbo ìyípadà sí `main`.

Gba `Sumi.zip` sílẹ̀, tú u, kí o sì gbé Sumi sí Applications. Ẹ̀yà kan ń ṣiṣẹ́ lórí Mac Apple silicon àti Intel méjèèjì.

Sumi kò ní ìbuwọ́lu Apple Developer ID, nítorí náà macOS dènà ṣíṣí àkọ́kọ́. Ṣí Ètò ẹ̀rọ › Àṣírí àti ààbò, tẹ Ṣí síbẹ̀, tàbí ṣiṣẹ́ àṣẹ yìí:

```sh
xattr -dr com.apple.quarantine /Applications/Sumi.app
```

## Ohun tí a nílò

macOS 14 tàbí tuntun sí i. Kíkọ́ rẹ̀ nílò Xcode 26 tàbí tuntun sí i (Swift 6.2).

## Kọ́ láti orísun

```sh
make app       # build/Sumi.app (universal: Apple silicon and Intel)
make run       # debug build, then open it
make install   # copy to /Applications
```

Ṣí fódà gẹ́gẹ́ bí iṣẹ́ àkànṣe láti Fáìlì › Ṣí… (⌘O), tàbí láti ìlà àṣẹ:

```sh
open -a Sumi path/to/project
```
