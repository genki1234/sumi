# Contributing to Sumi

Thank you for helping. Bug reports, fixes and translations are all welcome as GitHub issues and pull requests.

## Translating Sumi

Every piece of UI text lives in one plain-text file per language:

```
Localization/<language code>.lproj/Localizable.strings
```

Each line pairs the English text (left) with its translation (right):

```
"Save All" = "すべて保存";
```

### Fix a translation (no tools needed)

1. Open `Localization/<your language>.lproj/Localizable.strings` on GitHub.
2. Click the pencil icon (Edit this file). GitHub makes a copy of the repository for you.
3. Change the text on the right of `=`. Keep the quotes and the `;` at the end of the line.
4. Click Commit changes, then Propose changes. GitHub opens the pull request for you.

The CI check runs on the pull request and reports any line that is missing, unused or has broken placeholders.

### Add a new language

```sh
git clone <your fork>
cd sumi
swift scripts/l10n.swift add fr-CA     # language code: fr, pt-BR, zh-Hans, …
# translate Localization/fr-CA.lproj/Localizable.strings
swift scripts/l10n.swift check
```

Then open a pull request. A new folder under `Localization/` is all it takes: the build adds every folder to the app's languages and the Language menu automatically. Language choices take effect immediately and persist across launches. The 74 newly added locales and the language-menu labels were bootstrapped with machine translation; native-speaker corrections are welcome.

### Rules for translators

- Translate only the right-hand side. The left-hand side is the key the app looks up.
- Keep placeholders exactly: `%@`, `%ld`, `%1$@`, `%2$ld`. You may reorder them with the numbered form (`%2$@ … %1$@`).
- Keep keyboard symbols such as `⇧`, `⌘` and `…` as they are.
- A line left in English is shown in English. That is fine while a translation is in progress.
- Comments in the file are regenerated by the tool; put notes in the pull request instead.

### For developers: adding UI text

All user-visible text goes through `L("English text")` (see `Sources/Sumi/App/Localization.swift`). After adding or changing text:

```sh
swift scripts/l10n.swift sync    # adds the new keys to every language (in English for now)
swift scripts/l10n.swift check   # must print OK
```

Pull requests that add UI text should translate it into as many languages as the author can; the rest can follow in later pull requests.

## Code

- Build with `make run` (debug) or `make app` (release, universal). Requires Xcode 26 or later.
- The app is AppKit and Swift 6 (strict concurrency). Keep dependencies to a minimum.
- Keep each pull request to one change, and describe what it does and how you checked it in the running app.
- Sumi aims to stay small: an editor, a project view, search, highlighting, a terminal and previews. Discuss larger features in an issue first.
